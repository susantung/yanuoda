## 3. 详细问题

每条问题均记录所属流程、入口/前置数据、预期、实际、影响、级别、关联单据与复现状态。

### BUG-001｜资金流水缺少“调账”标签

- 所属流程：FL-13 资金流水与详情
- QA入口：PC后台 → 合作伙伴管理 → 资金流水
- 复现步骤：打开资金流水页面，检查业务标签。
- 方案/原型预期：标签依次覆盖“全部、充值、消费、退款、其他收入、调账”。
- QA实际：仅有“全部、充值、消费、退款、其他收入”，没有“调账”。
- 影响：无法按调账独立查询人工调账、调账-往来及退款调账，验收与财务追溯入口缺失。
- 严重级别：P1
- 状态：已复现

### BUG-002｜资金流水筛选区布局和展开逻辑不一致

- 所属流程：FL-13 资金流水与详情
- QA入口：PC后台 → 合作伙伴管理 → 资金流水
- 复现步骤：首次进入页面记录默认筛选；点击“展开”再次记录字段。
- 方案/原型预期：第一行“合作类型、合作伙伴、账户号”；第二行“账户类型、发生时间、查询、重置、展开”；展开后再显示“负责人、单据编号”。
- QA实际：默认直接展示“合作类型、合作伙伴、账户号、账户类型、负责人、单据编号”，发生时间被折叠到展开区。
- 影响：核心时间查询被隐藏，常用/高级条件排序与确认方案相反。
- 严重级别：P1
- 状态：已复现

### BUG-003｜资金流水出现不属于本页的业务按钮

- 所属流程：FL-13 资金流水与详情
- QA入口：PC后台 → 合作伙伴管理 → 资金流水
- 复现步骤：查看筛选区下方操作按钮。
- 方案/原型预期：标签行右侧提供“导出”和“配置列”；批量导入属于充值申请，调账等资金操作通过既定充值/调账入口处理。
- QA实际：资金流水页额外出现“批量导入”“资金操作”。
- 影响：页面职责和入口层级错误，可能产生重复入口及不同规则实现。
- 严重级别：P1
- 状态：已复现

### BUG-004｜部分消费/退款流水关键归属字段为空

- 所属流程：FL-13 资金流水与详情
- QA入口：PC后台 → 合作伙伴管理 → 资金流水 → 全部
- 前置数据：合作伙伴 `QA2-SMK-012-9328091` 的既有消费/退款流水。
- 复现步骤：查看2026-08-25 15:41至16:55期间的消费及退款记录。
- 方案/原型预期：每条流水均明确展示处理操作（消费/退款）、账户号和账户类型（挂帐/预付款）；只有无账户的其他收入使用“－”。
- QA实际：多条记录的“账户号”为“-”；部分记录“处理操作”为空，部分“账户类型”为空。例如16:55:59的+99.00记录处理操作为空、账户号为“-”；15:52:33的退款记录账户号和账户类型为空。
- 影响：无法判断资金归属的账户和业务类型，财务流水不可可靠追溯，且可能反映底层流水数据缺失。
- 严重级别：P0
- 关联单据：`3499638291833094144`、`3499572905250979840`、`3499571943178305537` 等
- 状态：已复现

### BUG-005｜资金流水表头多出“业务单号”列
