# 时间链路与演示票数据复核

本地原型函数检查，不代表真实接口或浏览器交互验收。

## 固定基准
比赛2027-01-03；项目报名2026-11-06 00:00:00至2026-11-21 23:59:59；单次2人；姓名与身份证必填。

## 计算口径
- 日历票先检查比赛日在实际配置日期集合中，再以本次比赛日计算开放、截止，再与原可售范围取交集。
- 固定期票按可售日期，不应用提前预订。
- 每票可报名时间自动取项目报名期与原票可售期的交集；有交集即可通过时间匹配，无需手填每票报名时间。无交集统一提示不匹配，保存时使用同一计算。
- 时间匹配不替代人数、资料、资格、上架状态校验。
