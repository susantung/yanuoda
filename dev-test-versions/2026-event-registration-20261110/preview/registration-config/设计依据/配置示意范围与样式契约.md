## 人数方案建议

运营自定义固定人数规格：可增行，每行名称可自定义，人数为正整数；一项目只有一种人数时只保留一行。共用项目表单，每位参赛者重复一份；不同人数分别关联票。游客端选择规格，不输入任意人数。该机制未获用户最终确认。

## 可操作范围与校验

字段选用、必填、自定义文本字段；新增人数行；按规格选择模拟票；票规则只读；人数与证件缺失及起售量冲突检查；无票免费分支；返回修改资料后更新校验。预订限购、窗口、证件范围为只读样例，真实动态校验不在本地实现。保存按钮仅保存在浏览器本地，明确模拟。
