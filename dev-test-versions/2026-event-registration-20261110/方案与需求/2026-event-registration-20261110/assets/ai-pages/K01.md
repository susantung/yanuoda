# K01｜对象、人数与数据口径

编辑源：[06-公共业务规则.md](../../06-公共业务规则.md)。本文件自动生成，请修改编辑源后重建。


| 对象 | 关系与规则 |
| --- | --- |
| 赛事 | 一场赛事下有多个项目；维护举办时间和介绍，不再设赛事统一报名时间 |
| 报名项目 | 独立报名/比赛日期、固定单次N、模板、签署要求、项目名额、免费/收费 |
| 收费报名项 | 一条关联票配置对应一个报名展示名称，最多20字；游客选该项，后续使用该原票，固定购买1张 |
| 免费项目 | 不关联门票、不做无票收款，不虚构报名项、票名、订单、支付或核销码 |
| 一份报名 | 固定N人共用一份报名，收费共用一笔当前有效订单；一份成功报名生成一张海报 |
| 示例与运营值 | 当前2027年1月3日、双人项目、500/398价格等为示例。实际名称、人数、价格、材料、图片均取正式配置 |

N为固定正整数，本期同项目只支持一种N，游客不可增减人数或购票数量。人数规则不同可拆项目，早鸟/正价则可为同项目的不同关联票项。

成功人数只统计收费实际付款成功或免费提交成功的人数，一份N人成功计N；暂存、签署、待提交、待付款均不计成功人数。项目显示成功人数/总名额；不限显示“成功人数/不限”。赛事按各项目汇总；任一项目不限则分母不限，无不限但有项目未完成名额配置则显示未配置，不把未知当0。
