**原型：**<a href="../../../../preview/event-admin/index.html" target="_blank" rel="noopener noreferrer">打开后台原型</a> → 赛事列表当前行“短信通知”。进入独立内部页签，携带当前赛事，不使用配置弹窗。

### 通知记录与模板入口

通知记录为主页面。顶部依次提供参赛人、手机号、报名项目、通知类型、发送状态筛选，查询、重置紧跟筛选项同一行；同次查询各条件共同生效，空条件不限制。姓名、手机号按输入内容匹配，项目、类型和状态按选择匹配。查询仅作用于当前赛事，不改变批量通知的接收范围。

筛选下方、记录列表上方靠右提供“新增模板”“批量发送延期通知”。记录展示参赛人、手机号、报名项目、通知类型、发送时间、发送状态、操作。发送状态仅包括待发送、发送中、成功、失败。操作列仅提供“查看内容”。列表提供勾选框，列表上方提供“批量重发”，未选择时禁用；发送中记录不可勾选。勾选后确认“已勾选xx条通知记录，确认批量重发？”，确认后关闭弹窗，提示“批量重发中，耐心等待，不要重复发送。”，清空勾选。每条使用原记录的接收人和实际内容，保留原记录并生成新的发送尝试，不读取后来修改的模板。缺少手机号不生成发送记录。

“新增模板”打开配置弹窗；首次未保存时选择报名成功通知/延期通知，保存后再次打开自动回显上次保存的通知类型及内容。切换通知类型时加载该类型已保存的模板，下方显示对应说明、模板内容、插入参数；已有该类型模板时回显并更新当前类型，不在同类型下创建多个生效模板。取消不保存，保存成功关闭弹窗。取消与保存按钮居中。

| 内容 | 规则 |
| --- | --- |
| 报名成功通知说明 | 报名实际成功后，分别向每位参赛者的手机号发送通知。修改模板仅影响后续通知。 |
| 延期通知说明 | 保存模板不会发送。点击“批量发送延期通知”并确认后，通知本赛事当时报名成功的参赛者。 |
| 模板正文 | 业务自行填写赛事名称、提醒及咨询文案；插入参数到光标处，不自动替换业务自定义文字 |
| `{参赛人姓名}` | 当前接收短信的参赛者姓名，不统一取发起人姓名 |
| `{报名项目名}` | 该参赛者对应报名项目名称，不取门票名称或报名选项展示名称 |
| 保存 | 空正文不得保存；保存到当前赛事及所选类型并回显，修改不追发历史通知 |

```text
【2027 首届呀诺达一二三热带雨林水陆挑战赛】
尊敬的{参赛人姓名}：恭喜报名成功！参赛组别：{报名项目名}
赛事信息详见「呀诺达雨林文化旅游区」公众号，如有疑问，可私信官方客服或拨打景区服务热线400-0463-888咨询。
```

### 报名成功发送

1. 免费报名最终提交实际成功、收费报名原订单实际付款成功后触发。仅取消支付、退款审核中等不作为新的成功事件。
2. 按本份报名的每位参赛者处理，收件号码取其本人填写的手机号。缺号不发送且不生成发送记录；不改为发给发起人，也不增加必填要求。
3. 同一手机号对应不同参赛者，仍各发一条，姓名分别替换。去重对象为同一次报名成功事件下的同一参赛者，不能仅按手机号去重。重复付款回调不重复发送；退款后重新报名实际成功属于新成功事件。
4. 使用触发时已保存的模板及对应数据形成该次通知内容，记录实际发送内容，后续改模板不改已有记录。短信失败不影响报名成功。
5. 未配模板时不发送、不阻断报名；发送服务、模板审核及接入约束见实施边界，不把本地模拟当成真实自动发送。

### 延期通知与记录

点击“批量发送延期通知”时先检查当前赛事是否已保存延期通知模板；未配置时提示“未配置延期通知模板，请先新增模板”，不创建任务。

有模板时统计本赛事当前实际报名成功且填写手机号的参赛者人数，按人计数，不按报名份数或不同手机号数计数；确认框显示“已成功报名xx人，确认全部发送延期通知？”。取消不发送；点击确认后关闭确认框，提示“批量发送中，耐心等待，不要重复发送。”，创建本批任务，处理中按钮不可重复触发。没有成功参赛者时提示无接收者，不创建空任务。

确认时重新核验成功状态并固定本批接收人、已保存模板及渲染内容，排除草稿、待签署、待提交、待付款和退款成功的已取消报名。缺少手机号的参赛者不计入确认人数，不生成发送任务或发送记录；不改发发起人手机号。之后新报名成功的人不自动加入已发批次。批量通知不受当前通知记录筛选条件影响，不自动改变比赛日期、订单使用日期或退款规则。

同一批次同一参赛者不得重复发送，同手机号不同参赛者分别处理。再次人工发起为新批次，需重新确认。实际延期文案及业务安排后续确认，原型参考文案不作为正式通知。

记录至少展示通知类型、参赛者、手机号、报名项目、触发/发送时间、发送结果及实际内容；延期按批次记录接收与成功/失败/待处理数量。失败记录可说明失败原因；页面仅显示上述四种发送状态。签完提醒发起人的短信仍为独立事项，不混入这两个模板。

### 原型与实施范围

本地可操作部分包括记录筛选、模板弹窗/类型切换/保存、缺模板提示、批量人数确认、处理中防重复及批量重发确认。人数取后台当前赛事报名成功且有手机号的参赛者样例记录，发送只模拟；真实回调、短信通道、服务端任务与回执尚未接入。报名成功未配置成功通知模板时不发送短信，也不影响报名成功。
