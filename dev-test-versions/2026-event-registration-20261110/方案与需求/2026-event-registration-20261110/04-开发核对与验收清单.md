# 赛事活动报名｜开发核对与验收清单

本文件是研发评审与后续验收预期，**不是已全部测试通过的报告**。真实接口均待核实接入，已做局部原型检查不替代服务端或真机验收。

## 一、开发边界与交付

报名新增赛事/项目配置、资料暂存/快照、材料阅读、逐人签署、记录及公开摘要查询；门票、订单、支付、超时、票券核销复用既有链路。原订单界面不改造。免费无订单/付款，收费固定购买所选项关联原票1张、传全部N人。

本目录分篇MD为源，HTML/完整PRD/页级AI文件为派生。原型仍在项目preview目录，旧评审ZIP未跟随局部更新；本轮全部调整完成再统一重打，不使用发送者本机地址作为研发交付地址。
