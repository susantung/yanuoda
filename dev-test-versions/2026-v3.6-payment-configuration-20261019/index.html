已确认的关键规则

  • 各页面先按启用、场景及资格筛选支付方式，再按序号升序展示，首次默认本页最小序号；允许跳号、序号不可重复。确认弹窗沿用已选方式，伙伴账户保持锁定，冲红初始不选。
  • 支付配置与支付资源管理保持两个并列菜单；扫码付、银行卡分别维护一份统一资源规则。
  • 团队允许九种支付方式；内导散客六种、内导团队九种，共用内导售票场景；长期合作伙伴仅默认账户对应的挂帐 / 预付款；临时客户固定挂帐。
  • 只按所选账号或实际窗口设备取资源，无配置不跨主体兜底；编号自动带出且只读。
  • 散客 / 团队资源在确认弹窗“一人一票”右侧；内导开单资源在原打印按钮右侧；结账补收资源在支付方式右侧；伙伴充值动态字段位于支付按钮下方。
  • 缺资源不拦主页面确认下单；在确认弹窗资源区域提示一次，阻止最终出票，取消后主页面不留资源错误。
  • 所有支付方式确认后沿用原处理；仅扫码付/银行卡新增每笔资源及柜台编码/POS编号记录，在订单支付、充值支付信息及内导各笔交易中展示。
  • 扫码付/银行卡可通过冲红更正同方式下的资源或编号；申请按发起账号/实际设备取资源，审核按该主体复核，同意成功后才更新有效支付，各次前后快照独立保存。
