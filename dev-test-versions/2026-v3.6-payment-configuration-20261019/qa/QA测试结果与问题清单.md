### PAY-001 现金与扫码付可以保存成相同排序号

P1 / 方案调整后关闭 / B01、B02

所属流程：FL03 支付配置；A61-02 排序号唯一性。

QA入口：后台 → 配置中心 → 支付配置 → 现金 → 配置。

影响：两个支付方式使用相同序号，无法按唯一序号确定先后，违反排序号不可重复的规则。

前置：现金原序号1，扫码付原序号2；均启用
