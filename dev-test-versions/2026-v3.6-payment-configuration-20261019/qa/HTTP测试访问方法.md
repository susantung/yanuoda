1. 通过Chrome扩展连接新建专用测试标签页，分别打开 `http://lvyou-ticket-3.qa.ly.com/#/payment-center/config` 与 `http://lvyou-ticket-3.qa.ly.com/windowTicket/#/ticket-sale`。
