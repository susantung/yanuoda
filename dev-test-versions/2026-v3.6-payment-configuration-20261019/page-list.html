支付配置化｜页面清单

版本：V1.4｜2026-10-19。编号与全程流程图、逐页方案一致。

一、后台页面

编号 菜单路径 / 入口 页面或弹窗 类型 本期内容
B01 ↗ 配置中心 → 支付配置 支付配置列表 新增 全部支付方式统一列表、启用状态开关、适用场景、处理及资源规则
B02 ↗ B01 → 配置 配置支付方式 新增弹窗 启停、适用场景多选；扫码付/银行卡统一资源归属与使用方式
B03 ↗ 配置中心 → 支付资源管理 支付资源列表 新增 当前景区的资源主数据、统一编码列、启停与编辑删除
B04 ↗ B03 → 新增 / 编辑 新增 / 编辑支付资源 新增共用弹窗 类型、名称、柜台编码/POS编号、启用状态
B05 ↗ B03 → 删除 删除确认 新增确认状态 已绑定拦截；未绑定二次确认，历史快照不受影响
B06 ↗ 基础信息 → 设备管理 设备管理列表 修改现有页 完整保留现网，仅窗口售票机增加收款配置
B07 ↗ B06 → 收款配置 设备收款配置 新增弹窗 当前归属为设备的支付方式，一套绑定跨场景共用
B08 ↗ 员工管理 → 系统角色 系统角色列表 修改现有页 完整保留现网账号管理，增加收款配置
B09 ↗ B08 → 收款配置 账号收款配置 新增弹窗 当前归属为账号的支付方式，一套绑定跨场景共用

配置中心只保留已有内容的菜单；支付配置、支付资源管理为两个并列菜单，不再增加场景菜单或页内双层切换。

二、售票窗口页面

编号 菜单路径 / 入口 页面或弹窗 类型 本期内容
W01 ↗ 售票 → 散客票 散客售票工作台 修改现有页 支付方式按统一配置过滤；主页面不放资源或编号
W02 ↗ 售票 → 团队票 团队售票工作台 修改现有页 九种支付方式可按配置使用；关联旅行社账户
W03 ↗ W02 → 选择旅行社 / 导游 原有对象选择弹窗 复用、回归 提供当前团队及账户上下文；不另建团队档案
W04 ↗ W01 / W02 → 确认下单 支付订单确认 修改共用弹窗 支付按钮、出票模式、现金或资源动态字段、资源校验及编号记录
W05 ↗ 售票 → 临时/长期合作伙伴 合作伙伴售票工作台 修改现有页 长期伙伴锁定默认账户支付；临时客户固定挂帐；长期伙伴充值入口
W06 ↗ W05 → 选择合作伙伴 / 临时客户 原有选择弹窗 / 临时状态 复用、回归 加载对象与账户，保留购物车；临时客户无充值入口
W07 ↗ W05 → 确认下单 合作伙伴支付订单确认 修改共用弹窗的账户状态 仅对应挂帐或预付款，不出现扫码付/银行卡
W08 ↗ 顶部合作伙伴 → 合作伙伴充值 合作伙伴充值列表 修改现有页 保留现有筛选、列及操作，行内充值统一调用 W09
W09 ↗ W05 充值 / W08 行内充值 合作伙伴充值 修改共用弹窗 五种支付按配置过滤；资源及编号新增记录，充值处理不变
W10 ↗ 售票 → 挂单列表 → 恢复 原有挂单恢复 复用逻辑调整 恢复票和游客后按当前身份及配置重算，不锁死旧资源
W11 ↗ 内导 → 导游开单 → 散客 / 团队 内导销售工作台及原有选择步骤 修改现有页 按内导场景过滤方式；原开单逻辑不变
W12 ↗ W11 → 确认下单 内导支付订单确认 修改现有弹窗 六种普通方式；团队另允许三种账户支付；现金/资源位于打印选项右侧动态区

W03、W06 是原有业务前置步骤；不是本期新增档案管理功能。W04、W07共用原有确认组件，不新建独立菜单。W09只维护一份组件和提交逻辑。

三、记录与详情

编号 路径 / 入口 页面 类型 本期内容
D01 ↗ 后台订单中心 → 现有散客/团队订单列表 → 详情；窗口现有订单查询、内导订单/交易记录 → 详情 订单详情 / 支付信息 修改展示 每笔扫码付/银行卡订单的“订单支付”新增资源及柜台编码/POS编号，原支付字段不变
D02 ↗ 窗口合作伙伴 → 账户充值记录 → 详情；后台现有对应账户充值记录 → 详情 充值/回款详情 修改展示 收款方式、资源名称、统一编码及原有充值字段
D03 ↗ 现有其他收入记录 → 详情 其他收入详情 复用展示关联 原关联及展示不变，不新增字段或记账规则

D01—D03不新增同名重复菜单。开发先按现有记录入口定位组件；后台具体二级菜单名称沿用当前系统。原型未完成真实历史详情联调，本方案定义其应落实的增量。

四、公共能力，不作为页面

编号 能力 使用位置
K01 景区配置读取、场景白名单、至少保留一种校验 B01/B02、所有窗口入口
K02 按账号/设备解析资源、默认与切换、失效拦截 B07/B09、W04/W09/W12
K03 提交前复核本期配置及资源；原交易处理不变 W04/W07/W09/W12
K04 每笔资源及编号记录、历史不回写 D01—D03及现有交易服务

五、本期不新增

  • 微信、支付宝等新线上支付接口；聚合支付继续使用现有建行链路。
  • 商户号、证书、密钥维护，平台开发配置、跨景区复制、恢复默认、独立配置历史页面。
  • 新的合作伙伴档案、授信、审批、临时客户回款/调账、退款/冲红操作流程。
  • 收银员日交款单及新的统计报表页面；不调整原统计口径。
  • 生产账号/设备自由切换控件。原型里的测试账号、测试设备不进入上线页面清单。
