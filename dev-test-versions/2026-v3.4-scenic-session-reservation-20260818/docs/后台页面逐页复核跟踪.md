# 后台页面逐页复核跟踪

> 用途：逐页确认管理小程序原型。单页未得到最终确认前，不把视觉稿和未决逻辑写入正式方案。
>
> 唯一正式方案为《场景活动预约管理功能 PRD》。本文件是页面准入检查表：页面确认后，必须同步更新正式 PRD、HTML 页面清单和对应原型。
> 本文件可以同时记录业务与视觉复核状态，但不承载实施细节；业务实施规则进入 PRD，视觉实施规则进入《HTML 原型页面样式清单 V3.4》。

## 复核方法

每个页面依次完成：

1. 页面目标、入口和返回路径。
2. 字段、状态、操作和默认排序。
3. 页面视觉及 320—414px 适配。
4. 空态、异常态和无配置数据样例。
5. 对其他页面、数据口径及主方案的影响。
6. 用户确认页面无问题后，再更新正式方案及相关页面。

所有 C01—C07 配置页统一执行“修改后标记未保存 → 保存当前步骤后更新游客端预览 → 最后一步发布后更新正式游客端”。未保存时切换步骤或离开页面，直接放弃修改并恢复上次保存结果；未保存内容不进入游客端效果。

C01—C07 顶部步骤导航保持单行横向滚动。手机端支持手指滑动，电脑端支持鼠标拖拽、触控板和滚轮横移；鼠标移动超过 8px 才判定为拖拽，短按标签必须切换下方配置页面，标签高亮与页面内容同步更新。

## A02 预约活动管理

## C01 基础信息

当前状态：`已确认，已同步正式 PRD`。

### 已确认的业务规则

- 活动名称必填，最多 30 字，同一景区允许重名。
- 活动 LOGO 选填，页面提示建议尺寸 400×400px；与 A02 列表卡片图片共用同一字段，保存新增、替换或删除结果后，列表必须同步更新。
- 未上传活动 LOGO 时，A02 列表显示主题色浅底和活动名称首字。
- 封面图片选填，页面提示建议尺寸 750×420px；与活动 LOGO 分开配置，只用于游客端预约详情页顶部封面。
- 封面标签选填、最多 16 字；封面主标题使用活动名称；封面副标题选填、最多 40 字。标签和副标题不填写时不展示，不允许固定写死样例文案。
- 详情介绍选填，使用图文编辑器；字号支持 11、12、14、16、18、24px，并支持文字颜色、插入图片和插入链接。
- 详情图片在游客端按内容区生成缩略展示，点击后可在当前手机可视区域中等比放大；后台游客端效果与正式游客端共用该规则。
- 联系人、联系电话选填；配置后在游客端详情展示，电话支持点击拨打。
- 创建人、创建时间、最后更新人和最后更新时间由系统记录，不允许人工修改。
- C01 不展示系统信息，创建与更新信息统一在 A02 列表及其“信息”展开区查看。

### 页面定稿结论

- 页面由配置页头、步骤导航、活动资料、联系信息和底部操作区组成，不单独展示系统信息。
- 封面标签和封面副标题各占一行配置；任一字段为空时，游客端连同容器、背景和间距一起隐藏。
- 底部“保存”和“下一步”拆分：“保存”只保存当前步骤并更新待发布预览，“下一步”只负责切换页面。
- 当前步骤存在未保存修改时，点击上一步、下一步或顶部步骤导航会直接放弃未保存内容，并恢复上次保存结果。
- “游客端效果”属于正式后台检查能力，复用正式游客端页面和组件，但读取当前活动最后一次保存的待发布配置；未保存内容不得进入预览。
- 正式游客端读取最后一次成功发布的配置；各步骤保存不会直接改变正式游客端，最终执行发布或发布更新后才整体生效。
- 详情图片在游客端以内容区缩略图展示，点击进入全屏大图查看层，点击遮罩或关闭按钮退出。
- 配置字段名统一使用 14px，必填/选填、字数和图片尺寸建议使用 12px；卡片标题使用 16px，字段说明不使用小于 12px 的微型字号。
- 底部主要操作按钮使用 14px；顶部步骤切换、游客端效果、素材操作和富文本工具使用 13px；保存状态提示使用 11—12px，不与操作按钮混为同一层级。
- 配置页头“编辑预约活动”使用 12px，当前活动名称使用 16px，形成“导航标题—活动名称—辅助说明”的清晰层级。
- LOGO 为空时，上传框只显示居中的上传图标和操作文字；列表首字占位说明移至上传框外，避免删除 LOGO 后文字堆叠和重心偏移。

### 后续开发约束

- 活动 LOGO、封面图片和详情图片的文件格式、大小与压缩阈值，在开发设计阶段统一补充。
- 富文本链接的目标类型、业务域名白名单和不可跳转时的提示，在小程序技术方案中补充。

### 本页验收点

- 活动名称、LOGO、封面标签、封面副标题、详情介绍和联系方式保存后再次进入不丢失。
- 上传、更换或删除活动 LOGO 后，A02 列表卡片使用同一字段更新；无 LOGO 时显示主题色浅底和活动名首字。
- 更换封面图片不改变 A02 活动 LOGO；待发布预览显示新封面，正式游客端在发布前保持原版本。
- 封面标签或副标题为空时，游客端不保留底色、空白容器或额外间距。
- 详情图片在 320、360、375、390、414px 均不横向溢出，可打开和关闭大图查看层。
- 未保存修改不能被“游客端效果”读取；切换配置步骤时直接放弃未保存内容并恢复上次保存结果。
- 320—414px 下活动名称、活动 LOGO 等字段名及其选填/尺寸标注均与管理端其他表单字号层级一致并清晰可读。
- 顶部步骤标签、游客端效果、上传/删除、富文本工具和底部按钮不再出现 9—10px 的过小操作文字。

## C02 必读须知

当前状态：`已确认，已同步正式 PRD`。

### 页面定稿结论

- 一个活动只配置一份须知，支持关闭、全局展示和按特殊提示展示。
- 弹窗标题、须知图文内容和阅读秒数均为必填配置。
- 须知内容与 C01 共用同一个图文编辑器和字号、颜色、加粗、图片、链接能力。

- 游客端按钮固定为“已读并确认以上内容（N）”，倒计时结束后可点击；点击遮罩关闭不选中日期。

### 本页验收点

- 开关、展示范围、标题、图文内容和阅读秒数均能保存并恢复。
- 未保存时禁止打开游客端效果；切换步骤会直接放弃未保存内容。
- 保存后的游客端预览与后台标题、内容、图片、链接和秒数一致。
- 关闭须知、全局展示、按特殊提示展示三种状态均有对应游客端结果。
