  1. 预约时段：每日开设7个班次（9:30—15:30，每个场次间隔1小时），每班次限流15人。购票成功后，请尽早选择心仪时段预约，系统将实时显示各时段余位。

  4. 集合点：呀诺达-溪降接待处。
