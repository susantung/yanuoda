# 程程票务系统版本迭代文档与培训文档集

上传本目录内容到站点根目录，域名默认访问 `index.html`。

- `dev-test-versions/`：开发与测试版本资料目录
- `business-versions/online-release-history/`：历史线上版本迭代说明
- `training/`：业务功能培训目录

## 更新历史线上版本说明

当前版本库由 `build-online-release-history.py` 根据《程程票务系统线上版本迭代说明.docx》生成。该脚本会将 Word 的标题、正文和内嵌图片转换为可浏览、可复制的独立 HTML 页面。

如后续有新的版本迭代说明，更新源 DOCX 后重新运行该脚本即可生成或更新版本页。
